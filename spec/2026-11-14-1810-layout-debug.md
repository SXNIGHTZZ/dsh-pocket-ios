# 布局调试模式：红框 + 编号

> **Status**: Draft
> **起始日期**：2026-11-14
> **预估工时**：80 分钟（单元累加）
> **文件名**：`spec/2026-11-14-1810-layout-debug.md`

## 背景 / 问题

调对话界面的间距时，双方只能用「上面那一行」「过程行和 DSH 那一行之间」这种描述交流。
一旦有两处相似的间距（比如 `groupSpacing = 7` 和 `MessageRow` 内部的 `VStack(spacing: 8)`），
就说不清指的是哪一个，来回确认好几轮。

需要一个**开发期可见、正式包可关**的开关：打开后给关键组件画出细红框 + 小字编号，
让「指哪打哪」变成「说 L2 太紧」。

## 目标与非目标

**目标**
1. 设置里新增「调试模式」开关（默认关闭）。
2. 开启后，关键布局组件显示 **0.5pt 红色描边** + **左上角小字编号**。
3. 编号表在设置页可见（编号 → 组件名 → 当前间距值）。
4. 关闭后完全无副作用（不改变任何尺寸、不参与布局）。

**非目标**
- 不做实时编辑间距（只做可视化定位）。
- 不覆盖所有 View（只覆盖调间距会用到的那些）。
- 不在 Release 里隐藏这个开关——用户要在真机上用它反馈问题。

## 参考实现（Prior art）

- **本项目 `Diagnostics`**：已有「诊断报告」这种开发辅助面，走同一套思路
  （`@AppStorage` 开关 + 只在 UI 上叠加，不改数据）→ **采用**。
- **SwiftUI 的 `.border()` / `.overlay()`**：标准做法，
  用 `.overlay { Rectangle().stroke(...) }` 不参与布局计算 → **采用**。

## 方案

### 编号表（固定，不要随意改）

| 编号 | 组件 | 当前间距 |
| --- | --- | --- |
| `L1` | 过程行（`ProcessRow`） | — |
| `L2` | 消息头（`✦ DSH` + 复制/引用按钮） | `groupSpacing` 7 / 内部 8 |
| `L3` | 消息气泡 | — |
| `L4` | 输入栏 | — |
| `L5` | 生成状态条（「深度求索中」+ 停止） | — |
| `L6` | 顶部导航 | — |

### 实现

1. **`LayoutDebug`**（`DSHPocket/Support/LayoutDebug.swift`）：
   ```swift
   enum LayoutDebug {
       @AppStorage("dsh-pocket.layout-debug") static var enabled = false
       static let entries: [(id: String, name: String, spacing: String)] = [...]
   }
   extension View {
       func layoutDebug(_ id: String) -> some View
   }
   ```
   modifier 内部：`enabled ? content.overlay(红框 + 编号).allowsHitTesting(false) : content`
   **注意 `.allowsHitTesting(false)`**：描边层不能吃掉点击。

2. **设置项**：`AppSettingsSheet` 加 `Section("调试")` + Toggle，下面列出编号表。

3. **打点**：在 `ConversationView` 给 `ProcessRow`、`MessageRow` 的消息头、气泡、输入栏、状态条应用。

### 视觉

- 描边：`Color.red.opacity(0.75)`，`lineWidth: 0.5`
- 编号：8pt、红色、左上角、白底 80% 衬底（深色气泡上也看得清）

## 被否决的方案

| 方案 | 否决理由 |
| --- | --- |
| 只打日志（打印各视图 frame） | 用户在真机上看不到，还是要靠猜 |
| 用 Xcode 的 View Hierarchy 调试 | 需要连 Xcode，用户手机不在电脑旁时用不了 |
| 编号自动化生成 | 编号必须是**稳定**的，用户记住才有意义；自动生成会随渲染顺序变 |

## 代价与风险

**代价**：约 100 行新代码 + 6 处打点。
**风险**：
| 风险 | 缓解 |
| --- | --- |
| 描边遮挡内容 | 0.5pt 极细 + `allowsHitTesting(false)` |
| 编号被看到以为是 bug | 只在设置里手动开启，默认关 |
| 忘记关掉就发版 | 默认值 false；发版前自查 `@AppStorage` 默认值 |
